# ⭐ Interactive Rating Component

Proyecto de maquetación web basado en el desafío **"Interactive Rating Component"** de Frontend Mentor.  
El objetivo fue construir un componente interactivo de calificación, permitiendo al usuario seleccionar un rating del 1 al 5 y mostrar dinámicamente un estado de agradecimiento sin recargar la página, aplicando manipulación del DOM, manejo de eventos y lógica con JavaScript moderno.

---

## 📌 Descripción

Este proyecto consiste en un componente interactivo donde el usuario puede seleccionar una puntuación para calificar una experiencia y enviar su respuesta mediante un formulario.

La interfaz permite mostrar un estado visual de selección, actualizar dinámicamente el mensaje del rating elegido y cambiar a una pantalla de agradecimiento después del envío.

Se puso especial énfasis en:

- Estructura semántica  
- Diseño responsive  
- Manipulación del DOM con JavaScript  
- Interactividad basada en eventos  
- Accesibilidad web  
- Código limpio y mantenible  
- Manejo de estado en JavaScript  
- Experiencia de usuario (UX) mediante retroalimentación visual

## 🎯 Características principales

- 📱 Diseño completamente responsive para mobile y desktop  
- ⭐ Selección interactiva de rating (1–5)  
- 🖱️ Interactividad basada en eventos (`click` y `submit`)  
- 🔄 Cambio dinámico de layout  
- 🎨 Estados interactivos mediante `hover` y `transition`  
- 🧩 Estilizado moderno con **Tailwind CSS**  
- ♿ Implementación de accesibilidad con `aria-pressed`  
- ⚡ Entorno de desarrollo moderno con **Vite**  

---

## 🧠 Aprendizaje

Durante este proyecto puse en práctica conceptos clave como:

- Manipulación del DOM con JavaScript  
- Uso de `addEventListener()` para manejar eventos `click` y `submit`  
- Manejo de estado básico usando variables en JavaScript  
- Uso de `data-* attributes` mediante `dataset`  
- Validación condicional para evitar envío sin selección  
- Manipulación dinámica de clases con `classList.add()` y `classList.remove()`  
- Modificación dinámica de contenido usando `textContent`  
- Diseño responsive utilizando **Flexbox** y utilidades de Tailwind CSS  
- Implementación de accesibilidad usando `aria-pressed`  
- Cambio dinámico de vistas utilizando el atributo `hidden`  
- Organización de un proyecto frontend moderno usando **Vite**
